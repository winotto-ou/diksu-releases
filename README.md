# Diksu

**Diksu** is Estonian dictation for Windows: speak and the text appears where you type, transcribe meetings (microphone and computer audio at once) and audio files. Everything runs on your own computer.

This repository holds only Diksu's releases: the Windows installers and the word list that installed copies update themselves from. The source code is not public.

- Download and buy: **https://diksu.ee**
- Newest installer: [Releases](https://github.com/tehumehu/est-dictate-releases/releases/latest)

---

**Diksu** on eestikeelne dikteerimine Windowsile: räägi ja tekst ilmub sinna, kuhu kirjutad. Diksu teeb ka koosolekutest (mikrofon ja arvuti heli korraga) ja helifailidest teksti. Kõik toimub sinu enda arvutis.

Siin hoiustes on ainult Diksu väljalasked: Windowsi paigaldajad ja sõnastik, mille järgi paigaldatud Diksu end uuendab. Lähtekood ei ole avalik.

- Allalaadimine ja ost: **https://diksu.ee**
